# Harshavardhan — Full Stack Developer Portfolio

A responsive, high-performance developer portfolio built with React 19, TypeScript, TanStack Start, Tailwind CSS, and GSAP. Features an interactive space & galaxy aesthetic, interactive cursor physics, scroll-driven sticky card stacking, and instant theme switching.

---

## 🛠️ Tech Stack

- **Framework**: React 19 & TanStack Start
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4 & Lucide Icons
- **Animations**: GSAP (ScrollTrigger, Easing, Physics)
- **Tooling**: Vite & Cloudflare Nitro

---

## 🚀 Featured Projects

1. **AsurionCares AI Support Agent**
   - *Python · LLM (Claude API) · TF-IDF Retrieval*
   - Intelligent customer inquiry triage, automated context retrieval, and reasoned human escalation.

2. **Community Care**
   - *React.js · Node.js · Express.js · MongoDB · Google Maps API*
   - Full-stack community aid locator with real-time geolocation navigation and verified aid directory.

3. **Text-to-Image Generation**
   - *Python · TensorFlow · LSTM · CNN*
   - Dual deep learning pipeline combining LSTM recurrent text embeddings with CNN generative image synthesis.

## 💻 Local Development

```sh
# Clone repository
git clone https://github.com/harshavardhan7405/portfolio.git

# Navigate to project folder
cd portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

Build for production:
```sh
npm run build
```
